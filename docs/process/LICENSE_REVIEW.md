# License decision — 2026-11-02

**Decision: retain the current MIT license pending maintainer/legal review.** The owner asked whether to switch to a “more secure” license. A software copyright license is not a technical or clinical security measure. MIT is permissive, provides an as-is warranty disclaimer, and allows commercial reuse. A copyleft license (e.g. GPL/AGPL) changes downstream sharing obligations but does not certify safety or prevent misuse of medical research.

A change would need confirmation of copyright ownership and existing contributor grants, intended compatibility, goals for downstream redistribution, and a prospective transition plan. **Previously granted MIT permissions generally cannot be unilaterally withdrawn from existing copies.** Do not add a noncommercial restriction and still call the project open source.

Security/privacy practices and clinical safeguards belong in SECURITY.md, PRIVACY.md, CI and the review process rather than a hasty license change. Seek qualified legal advice before relicensing.
