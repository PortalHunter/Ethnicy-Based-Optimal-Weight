# Reproduce Argentina software checks

Use the exact input commits and commands in `argentina-native/REPORT.md` and the Actions `report.json`; these are immutable calibration inputs, not new research authorization.

For the original native rerun, clone the repository, fetch the four pins listed in the report, detach at publication, and put the archived native evidence under `/tmp/atlas-argentina-verifier-logs`. The preservation script deliberately uses that absolute output directory and reads the included ticket.json. It runs from the published repository working directory. Extract harness.py, checkout.py, state.json, test_harness.py and test_checkout.py **byte-for-byte** from the reported architecture commit into that evidence directory; do not use the copies on main. Put packet.json from ticket.packet there. Set `PYTHONDONTWRITEBYTECODE=1`, then execute the exact report commands. The script computes receipt.json and fingerprints.json; generated outputs must match the retained files. No external package dependencies are needed.

The two hosted runs use the identical installed runner at their exact request/workflow commits. The per-run archived directories retain every artifact entry as text, plus the original ZIP SHA256 in TRANSITION_STATUS.md. `report.json` maps each command to its log. Read `01.log` through `04.log` for hosted versions and `34.log` through `37.log` for required structural/native checks. Artifact listings and full job logs were independently fetched through the GitHub connector; the Verifier report records that audit. Re-running after check-in is expected to fail the running-ticket guard. Do not reopen or reserve the completed case to reproduce historical software checks.

Prepublication mode requires an immutable candidate commit already fetchable from GitHub. Creating/staging that candidate is a separate explicitly authorized Writer operation; this workflow grants no staging or research write authority and never advances a team ref. Only the published Argentina path has been exercised end to end. Other team adapters remain configured, untested by this transition, and subject to their live holds and separate required evidence gates.
