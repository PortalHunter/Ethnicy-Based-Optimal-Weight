# Global Health Atlas table preview

Open `index.html` in a browser. The preview reads its versioned data locally and provides institution and area-coverage views. Institution details distinguish location, territorial remit, cross-border services, and source roles. Area coverage keeps unknowns and conflicting evidence visible. The condition filter identifies research availability and leaves clinical applicability unassigned.

## Update the projection

The committed `data.js` is generated by the projection script from the immutable Team E research handoff in draft PR #150. It includes directory identity, coverage, citation URLs and bounded source roles. Clinical claims, ancestry mappings, private inputs, raw discovery leads, and provisional directory identities are excluded. Team B identities use a positive state allowlist. Team A authority roles require a census relation and a public HTTPS citation.

From the repository root:

```sh
git fetch origin research/atlas-team-e-20261126
python3 scripts/build-atlas-preview.py
python3 scripts/build-atlas-preview.py --check
node --test tests/atlas-preview.test.mjs
```

Review any change to the approved snapshot or allowed fields before rebuilding the public-facing projection.
